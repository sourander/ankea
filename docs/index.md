# Project Overview

Ankea is a simple flashcard application inspired by Anki. The purpose of the project is to let a user create flashcard decks, add cards into those decks, and practice the cards through a lightweight study view.

The application is written in Java and uses JavaFX for its graphical user interface. It is being developed as a university course project for **Ohjelmointi 2** at University of Jyväskylä.
